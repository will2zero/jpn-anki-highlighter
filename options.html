ANKI CONFIG

AnkiConnect

The highlighter needs to know where your AnkiConnect server is running.

Use the address and port configured for AnkiConnect. For IPv6, include brackets, for example [::1]. AnkiConnect must allow this extension's origin in its CORS settings.

SITE CONTROLS

Excluded sites

The highlighter will stay quiet on these websites.

One hostname per line. Subdomains are included automatically.

Only connect to an AnkiConnect server you trust. Mature means an Anki review interval of at least 21 days. The highlighter only colors text; it does not add lookups or intercept Yomitan.
